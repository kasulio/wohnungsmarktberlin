# Glossary

UI copy is German; code is English. When a word below appears in code, it means exactly this.

| Term                                         | Meaning                                                                                                                                                                                                |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Hausverwaltung / PropertyManagement (PM)** | A housing company whose site we scrape (degewo, gewobag, howoge, …). One file per PM in `data/propertyManagements/`, keyed by `slug`.                                                                  |
| **Flat**                                     | One rental listing (`flat` table), unique by `url`.                                                                                                                                                    |
| **flatUrlJob**                               | A queued listing URL waiting to be fetched and parsed. Discovery (sync) and extraction are separate cron tasks.                                                                                        |
| **Sync**                                     | `extractUrls()` for one PM: enqueue new URLs, refresh `lastSeen`, soft-delete flats no longer listed.                                                                                                  |
| **Extract**                                  | Fetch a job's HTML and run `extractDataFromHtml()` into a `ScrapedFlat`.                                                                                                                               |
| **Soft-delete / stale**                      | `flat.deleted` set to a timestamp. Flats not seen for 7 days are pruned this way.                                                                                                                      |
| **Ignored**                                  | `flat.ignored = true`: scraped but never shown (parking, commercial, provider-specific junk). Decided at extract time by `shouldIgnoreListing`.                                                        |
| **Filtered**                                 | Hidden by the user's own filters in the UI. Unrelated to ignored.                                                                                                                                      |
| **Publishable / visible**                    | Shown publicly: not deleted, not ignored, and geocoded (`addressId` set). Notifications fire on the transition into publishable, not on insert.                                                        |
| **Address improvement**                      | Geocoding a flat's address via Photon (photon.komoot.io) into the `address` table.                                                                                                                     |
| **Bezirk / district**                        | Berlin borough, derived from the postal code (`data/districts.ts`).                                                                                                                                    |
| **WBS**                                      | Wohnberechtigungsschein: an income-based permit some flats require. Surfaces as a tag.                                                                                                                 |
| **Tag**                                      | Label derived from the listing title at read time (`data/tags.ts`). Not persisted; the `tag` tables are legacy.                                                                                        |
| **Fixture**                                  | Saved listing HTML in `data/fixtures/` with expected values; the offline scraper tests.                                                                                                                |
| **Canary**                                   | `bun scrape:canary`: extracts a few live listings per PM to catch site changes.                                                                                                                        |
| **Subscriber / channel / ledger**            | Notification target (e.g. a Telegram chat), its delivery transport (`telegram`, `log`), and the record of what was sent (`notificationSubscriber`, `notificationSent`). The `notify` task sweeps them. |
